S7

Kronecker v2 — the dynamic byte window

Byte-built embeddings see only the first 32 bytes of a token. For English that's 32 characters; for Tamil it's ten — and past that, distinct words silently become the same vector, forever.

  • census1,154 tokens collide in a real 131,072 vocabulary — 92% of them Indic
  • asymmetrya Tamil token is 61× likelier to be destroyed than a Latin one
  • fixcompute position instead of storing it: no cap, 4× smaller, better spelling similarity
  • proof v1 pinned at 0.500 on a task the new codec solves at 1.000
