Start with activations ↓

S1-1

Activations exist for a reason.

A model with no nonlinearity can only draw a straight boundary, so it cannot separate two concentric rings. Add a single ReLU hidden layer and it wraps the ring. Only the activation changes.

Press train. The linear model gets a straight line; the ReLU model gets a ring.

S1-2

Depth without nonlinearity is a lie.

Five stacked linear layers collapse to a single linear map — so a 5-layer linear net is no stronger than 1 layer. Both fail identically. Insert ReLUs between the same five layers and it suddenly solves the ring.

The first two boundaries will be the same line. The third breaks the tie.

        S1-4
        
Memorization vs generalization — data closes the gap.

      

      

        One high-capacity net, one noisy task, three dataset sizes. On 20 points it drives train
        accuracy to ~100% while held-out accuracy stays poor — it memorized the noise. Grow the
        data and the train/test gap shrinks.

How this works

      

        There is no server and nothing precomputed. Every boundary above is trained on your
        machine, in JavaScript, the moment you press a button — so what you see is the model
        actually learning, not a recording of one.
      

      

        

          
The engine

          
Each model is a real neural net built with TensorFlow.js and trained by gradient descent (Adam) right in the page. Tiny nets, so it runs on the CPU backend in seconds.

          
The plane is coloured by sampling the model on a 64×64 grid and painting P(class 1) — teal→coral. The white valley between them is the decision boundary.

        

        

          
The data

          
S1-1 & S1-2 use two noisy concentric rings — deliberately not linearly separable. S1-4 uses noisy two-moons with a fraction of labels flipped, so a small dataset can memorize the noise.

          
S1-3 uses a toy grammar where animals, fruits and verbs share next-token distributions — the only signal the embedding ever sees.

        

        

          
The seed control

          
The random seed up top regenerates every dataset. Change it (or hit New sample) and Retrain: the numbers wobble a little, but the story never does. That is the point — the result is the phenomenon, not one lucky run.

        

        

          
Reading the proofs

          
S1-2 also multiplies the five weight matrices numerically — K1·K2·K3·K4·K5 collapses to one 2×1 map, which is why stacked linear layers can only draw a line.

          
Every claim is re-run headless in verify/ so the numbers here match a reproducible check, not a screenshot.
